Lumaris — Valley of a Thousand Lights: a travel poster for a place that isn't there. At dusk, a thousand lanterns rise over a winding river beneath a violet sky. The poster is drawn with Python PIL: a gradient dusk sky, a low glowing sun, layered mountain silhouettes, and lanterns rising into the night.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `poster.png` to `out/entry.png`.
